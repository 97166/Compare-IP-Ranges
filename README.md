# Compare-IP-Ranges
This PowerShell script takes input of IP ranges and compares them with the IP ranges configured in SCCM and gives you the missing IP ranges

#How to Use
1. Add your Site Code
2. Add the server name where your SMS Provider Exists
3. In @ranges container, paste the IP ranges as strings, for eg: '10.24.25.54-10.24.25.20'
